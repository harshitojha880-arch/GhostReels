# 👻 GhostReels Studio

**GhostReels** is a fully autonomous, 24/7 Faceless Video Generation Pipeline for Android (Termux) or Linux VPS. It writes scripts, generates AI images, creates realistic voiceovers, adds motion, burns subtitles, and packages SEO titles & thumbnails — 100% hands-free.

Whether you run a **Dark Psychology** channel, a **True Crime** documentary page, or a **Finance** automation channel, GhostReels builds the videos while you sleep.

## ✨ Key Features
- **Multi-Niche Engine:** Dark Psychology, True Crime, Finance, etc.
- **100% Autonomous:** Runs in an infinite loop.
- **Crash-Resume Technology:** If the phone dies, it resumes exactly where it left off.
- **Thermal & RAM Safe:** Pauses automatically if the device exceeds 45°C.
- **Ultra-Secure Licensing:** Device-locked activation to protect your purchase.

## 🛠️ Prerequisites
1. **Android Phone** (Minimum 4GB RAM) OR Linux VPS.
2. **Termux App:** Download from F-Droid (Do NOT use Play Store).
3. **4 Free API Keys:** Instructions below.
4. ## 🔑 Step 1: Get Your Free API Keys

GhostReels uses a smart 4-layer fallback system to ensure you never hit rate limits. Create these free accounts and copy your keys:

1. **Groq (Primary):** Go to console.groq.com -> API Keys -> Create Key.
2. **Gemini (Fallback):** Go to aistudio.google.com -> Get API Key.
3. **NVIDIA (Fallback):** Go to build.nvidia.com -> Get API Key.
4. **Agnes AI (Images):** Go to platform.agnes-ai.com -> Create Secret Key.

## 💡 Pro-Tips for 24/7 Running
- Keep the phone plugged into a charger.
- You can turn off the screen (Termux uses wake-lock).
- Press `Ctrl + C` to stop.
- If it crashes, just type `ghostreels` again to resume.

## 🛠️ Troubleshooting & FAQ
- **Rate Limit Exceeded:** The system automatically rotates between Groq, Gemini, and NVIDIA. Wait 10 minutes.
- **License Error:** You are on the wrong device. Contact the seller.
- **FFmpeg Hung:** Press `Ctrl + C` and type `ghostreels` again.
